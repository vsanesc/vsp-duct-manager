# Contributing

**Pull requests are not accepted for now.** This is an early-stage personal project and the
design is still changing, so external code contributions would be hard to review and merge.
Unsolicited pull requests will be closed without review.

**Issues and bug reports are welcome.** If something does not work, please open an issue with:

- what you ran (command and config; use `duct_config.example.yaml` values if you can),
- what you expected and what happened (full error output),
- your Python version (must be 3.13) and OpenVSP version (3.55.0).

Feature ideas and questions are welcome as issues too. Please do not attach `.vsp3` models or
configs that contain data you do not want public.

You are free to fork the project under the terms of the [GPL-3.0-or-later](LICENSE) license.
